# 🚕 מונית משותפת · רעננה (share-taxi)

אתר קטן לתיאום מוניות משותפות (שירוטל) באזור רעננה — אנונימי לגמרי, בלי הרשמה, בלי טלפונים.

## מה יש בו
- מי שמחפש מונית מפרסם: כיוון (לרעננה / מרעננה), נקודת מוצא, יעד, תאריך ושעה, גמישות, והערה קצרה (למשל "בדרך", "2 מקומות").
- התיאום נעשה בתוך האתר דרך תגובות אנונימיות, כולל תשובות מהירות ("בדרך! 🚕").
- כל דפדפן מקבל טוקן אקראי שמאפשר לו למחוק רק את הפרסומים שלו.
- פרסומים פגים אוטומטית 6 שעות אחרי שעת היציאה.

## טכנולוגיה
- Cloudflare **Worker** (API) + **KV** (אחסון) + **Assets** (קבצים סטטיים) — הכל בתוכנית החינמית.
- אין בקשות רשת חיצוניות, אין מסד נתונים, אין סודות בריפו.

## פיתוח מקומי
```bash
npm install
npm run dev        # רץ על http://localhost:8787
```

## פריסה
1. יוצרים namespace ל-KV ומעתיקים את ה-id:
   ```bash
   npm run kv:create
   ```
2. מדביקים את ה-id ב-`wrangler.jsonc` במקום `REPLACE_WITH_KV_NAMESPACE_ID`.
3. מעלים:
   ```bash
   npm run deploy
   ```

ה-id של ה-KV אינו סוד ואפשר להשאיר אותו בריפו. אין לשים בריפו טוקנים או מפתחות API.
