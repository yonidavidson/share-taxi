# 🚕 מונית משותפת · גב-ים רעננה (share-taxi)

אתר קטן לסגירת **הקילומטר האחרון** — תיאום מוניות משותפות (שירוטל) בין תחנות הרכבת
(רעננה מערב, רעננה דרום, הרצליה) לבין מרכז העבודה בגב-ים רעננה, ובכיוון ההפוך. אנונימי לגמרי,
בלי הרשמה, בלי טלפונים.

## מה יש בו
- **לוח חי** בראש העמוד: הרכבות הבאות בכל תחנה (2 מגיעות + 2 יוצאות, כולל רציף, איחורים
  וסטטוס ביטול), הערכת זמן נסיעה ברכב/מונית (עם תנועה בזמן אמת) ואומדן מחיר.
- **"מתי אני בבית"**: בחירת תחנת הבית, ומסלולי הגעה דרך שלוש התחנות עם רציפים,
  החלפות, זמני המתנה ו"צאו עד".
- **התראות Push**: 🔔 על נסיעות מתאימות בכיוון שלך ועל תגובות לפרסום שלך (אפשר לבטל).
- **"אני על הרכבת"**: פרסום מהיר בלחיצה שהרכבת שלך מגיעה.
- פרסום כולל מספר נוסעים (👥), כיוון (לעבודה/הביתה), תחנה, תאריך ושעה וגמישות.
- מסלול מותאם: מ**רכבת רעננה מערב**, **רכבת רעננה דרום** או **רכבת הרצליה** — אל **גב-ים רעננה**
  ובחזרה.
- מי שמחפש מונית מפרסם: כיוון (אל גב-ים / חזרה), תחנה, תאריך ושעה, גמישות, והערה קצרה
  (למשל "בדרך", "2 מקומות").
- התיאום נעשה בתוך האתר דרך תגובות אנונימיות, כולל תשובות מהירות ("בדרך! 🚕").
- כל דפדפן מקבל טוקן אקראי שמאפשר לו למחוק רק את הפרסומים שלו.
- פרסומים פגים אוטומטית שעתיים אחרי שעת היציאה (לפי שעון ישראל), וקרון של Cloudflare מנקה הכל
  כל 3 שעות — הלוח תמיד נקי.
- הצפייה פתוחה לכולם; רק פרסום ותגובה משויכים לטוקן האנונימי של הדפדפן.
- PWA — אפשר להתקין למסך הבית (כפתור התקנה צף, כולל רמז לאייפון).

## חוויית שימוש (GTA style)
- מסך **MISSION PASSED** עם ג'ינגל מסונתז ורטט בנייד כשפרסום עולה ללוח.
- מונה חי מעל הלוח ("N מחפשים · M בכיוון שלך") עם אנימציה כשמצטרפים.
- כניסת כרטיסים בהדרגה, מונית חולפת בכניסה, ושלד טעינה (shimmer) ללוח החי.
- מתג צליל 🔊/🔇 בכותרת (ההעדפה נשמרת במכשיר).
- Service Worker במצב network-first — עדכונים תמיד מגיעים, ועובד גם בלי רשת.

## טכנולוגיה
- Cloudflare **Worker** (API) + **KV** (אחסון) + **Assets** (קבצים סטטיים) — בתוכנית החינמית.
- נתוני הרכבות מגיעים מ-`rail-api.rail.co.il` — אותו API לא רשמי שאליו מדבר אתר רכבת ישראל
  (ראו [yonidavidson/rakevet](https://github.com/yonidavidson/rakevet)). התשובות נשמרות במטמון KV
  לשתי דקות כדי לא להעמיס על ה-API, עם הגשת מטמון ישן אם המקור נופל.
- מפתח ה-API פומבי (מוטמע באתר rail.co.il) ואינו סוד. אין מסד נתונים ואין סודות אחרים בריפו.
- אין בקשות רשת חיצוניות מהדפדפן (חוץ מהגופנים) — כל קריאות הרכבות נעשות בשרת.

## תנועה בזמן אמת (אופציונלי)
זמני הנסיעה ברכב/מונית בין התחנות לגב-ים מחושבים עם תנועה חיה מ-**TomTom** כאשר מוגדר מפתח API:
```bash
npx wrangler secret put TOMTOM_API_KEY
```
בלי מפתח — האתר מציג הערכת עומס לפי שעה ויום (מסומן "הערכה" בלוח החי). המפתח נשמר כסוד ב-Cloudflare ואינו בריפו.

## פיתוח מקומי
```bash
npm install
npm run dev        # רץ על http://localhost:8787
npm test           # בדיקות (Node test runner)
```

## פריסה
1. יוצרים namespace ל-KV ומעתיקים את ה-id:
   ```bash
   npm run kv:create
   ```
2. מדביקים את ה-id ב-`wrangler.jsonc` במקום `REPLACE_WITH_KV_NAMESPACE_ID`.
3. מעלים:
   ```bash
   npm run deploy
   ```

ה-id של ה-KV אינו סוד ואפשר להשאיר אותו בריפו. אין לשים בריפו טוקנים או מפתחות API.
